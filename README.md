# Search an Element in a List

## Explanation

This program searches for a specific number in a list and reports whether it exists.

## Problem Statement

Write a Python program to search for an element in a list and display its position.

## Features

* Accepts a list
* Accepts a search value
* Searches the list
* Displays the position if found

## How It Works

The program uses a loop to compare the search value with every element in the list.

## Technologies Used

* Python 3

## Data Structure Used

* List

## Methods Used

* `input()`
* `split()`
* `map()`
* `enumerate()`

## Program Flow

1. Read the list
2. Read the search value
3. Check each element
4. Display its position if found
5. Display not-found message otherwise

## Sample Input

```text
10 20 30 40 50
30
```

## Sample Output

```text
Element found at position: 2
```
